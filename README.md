# Проверка скорости загрузки

Небольшая консольная утилита на Python для измерения эффективной скорости загрузки по одному HTTP(S)-адресу. Скрипт выполняет **10 последовательных GET-запросов** и дожидается полной загрузки каждого ответа перед началом следующего.

## Возможности

- Выполняет ровно 10 последовательных GET-запросов.
- Считает запрос завершённым только после чтения всего тела HTTP-ответа.
- Читает ответ частями по 64 КиБ, поэтому не загружает весь файл в оперативную память.
- Показывает время каждого запроса, среднее время, общий объём скачанных данных, общее время выполнения и скорость загрузки.
- Обрабатывает HTTP-ошибки, сетевые ошибки, таймауты и прерывание пользователем.
- Проверяет TLS-сертификаты HTTPS-серверов стандартными средствами Python; проверка сертификатов не отключается.
- Использует только стандартную библиотеку Python — устанавливать сторонние пакеты не нужно.

## Требования

- Python 3.10 или новее.
- Доступ к HTTP- или HTTPS-адресу, который возвращает файл или другой загружаемый ресурс.

## Запуск

Передайте URL первым аргументом. Для быстрой проверки можно использовать одну из проверенных ссылок ниже.

### Быстрая проверка — небольшое изображение PARSE Observer

```bash
python speed_test.py "https://parse.observer/api/public/insights/covers/en/telegram-marketing-keyword-b2b-audience-research/85?shape=lead&size=large"
```

Изображение небольшое (около 46 КБ), поэтому этот вариант подходит для проверки доступности URL и корректной работы скрипта, но не для оценки пропускной способности канала.

### Проверка на большом файле — около 10 МБ

```bash
python speed_test.py "https://loremfile.dev/jpg/10mb.jpg"
```

Скрипт скачает файл 10 раз последовательно — примерно 100 МБ данных за один запуск. Это более показательный вариант для оценки скорости загрузки.

Обе ссылки успешно проверены при подготовке тестового задания: сервер вернул HTTP 200, все 10 ответов были скачаны полностью. Доступность сторонних серверов может меняться.

### Если сервер не проходит проверку TLS-сертификата

Для HTTPS скрипт проверяет сертификат сервера стандартными средствами Python. Если проверка не проходит, программа выводит отдельное пояснение с именем хоста и завершает работу. Причиной может быть недействительный или неполный сертификат сайта, локальное хранилище доверенных сертификатов либо HTTPS-прокси. Проверка сертификатов намеренно не отключается: использование HTTPS без проверки сертификата небезопасно.

Адрес `https://example.com/large-image.jpg` из формулировки задания — лишь пример формата URL, а не гарантированно существующий тестовый файл. Для проверки используйте две ссылки выше.

По умолчанию таймаут каждого запроса составляет 30 секунд. Его можно изменить параметром `--timeout`:

```bash
python speed_test.py "https://loremfile.dev/jpg/10mb.jpg" --timeout 60
```

## Пример вывода

```text
Результаты запросов:
  01/10: HTTP 200, 8.42 МБ, 1.284 с
  02/10: HTTP 200, 8.42 МБ, 1.197 с
  ...
  10/10: HTTP 200, 8.42 МБ, 1.213 с

Итоги:
  Количество запросов:   10 (последовательно)
  Всего скачано:         84.20 МБ (84,200,000 байт)
  Среднее время запроса: 1.231 с
  Общее время:           12.320 с
  Скорость загрузки:     6.84 МБ/с
```

Числа в примере приведены для иллюстрации. Фактические результаты зависят от адреса, сервера, маршрута до него и текущих условий сети.

## Как рассчитываются показатели

- **Время запроса** — интервал от начала открытия соединения до момента, когда полностью прочитано тело ответа.
- **Среднее время запроса** — среднее арифметическое времени выполнения всех 10 запросов.
- **Объём скачанных данных** — сумма байтов, прочитанных из тел всех 10 HTTP-ответов. HTTP-заголовки и служебные накладные расходы транспортного уровня в это значение не входят.
- **Скорость загрузки** — общий объём данных из тел ответов, разделённый на полное время выполнения серии из 10 запросов.
- **Единицы измерения** — десятичные мегабайты в секунду (`МБ/с`), где `1 МБ = 1 000 000 байт`.

Для уменьшения влияния кэширования и сжатия скрипт отправляет заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`. Это не гарантирует обход всех промежуточных кэшей: поведение зависит от сервера и инфраструктуры между клиентом и сервером.

Утилита измеряет скорость загрузки на уровне HTTP для указанного URL, а не проводит комплексный тест скорости интернет-провайдера. На результат влияют удалённый сервер, размер файла, CDN и кэширование, установка TLS-соединения и состояние сети.

## Запуск тестов

```bash
python -m unittest discover -s tests -t . -p "test_*.py" -v
```

Тесты используют локальный HTTP-сервер и проверяют, что скрипт выполняет ровно 10 запросов и правильно суммирует объём тел ответов.
